# ПрофАвто

Статический сайт на HTML, CSS и JavaScript. Предназначен для GitHub Pages, ресурсы подключены относительными путями.

## Предпросмотр

Выполнить `npm start` и открыть http://localhost:4194. Требуется Node.js, установка зависимостей не нужна.

## Проверка

`npm run check` проверяет синтаксис JavaScript. Вёрстку и взаимодействия проверять в браузере на компьютере и телефоне.

## Публикация

Сайт — https://cruel-anarchist.github.io/profauto03.ru/

Репозиторий — https://github.com/cruel-anarchist/profauto03.ru

GitHub Pages публикует корневой каталог ветки main. После коммита изменений выполнить `git push origin main`. GitHub автоматически обновит сайт. index.html является главной страницей. Собственный домен подключается отдельно.
